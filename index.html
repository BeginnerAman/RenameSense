Architecture & Safety

Engineered with Invariant Safety Guarantees

RenameSense adheres to strict operating principles to ensure your filesystem remains protected against corruption or accidental loss.

Atomic WAL Journaling

Intent is flushed to disk before any file is touched. Powered by durable JSONL write-ahead logs, guaranteeing full transaction replay or rollback even after power loss.

Pre-Flight Collision Shield

Proactively blocks duplicate target names, existing target collisions, illegal Win32 characters (< > : " / \ | ? *), and Windows reserved names (CON, PRN, AUX, NUL).

Two-Phase Case Staging

Windows NTFS is case-preserving but case-insensitive. Changing photo.jpg to PHOTO.JPG stages through a deterministic temporary UUID to prevent destructive collisions.

Extended Win32 Paths

Transparent extended path handling (\\?\) handles deeply nested folder structures exceeding the legacy Windows 260-character MAX_PATH ceiling.

High-Volume Virtualization

Optimized memory footprint and virtualized row rendering cleanly handles 50,000+ files in under 10ms with zero frame drops or UI freezing.

100% Offline & Telemetry-Free

Runs exclusively on your device. Zero internet connection required. No telemetry, no background analytics, and no file metadata ever leaves your computer.

Frequently Asked Questions

Answers to Common Questions

Everything you need to know about safety, installation, licensing, and file recovery.

What is the difference between the Setup Installer and Portable ZIP?

The Setup Installer (58.1 MB) installs per-user into your local application directory, creates Start Menu and Desktop shortcuts, and registers the Windows Explorer right-click menu. The Portable ZIP (79.4 MB) requires no installation: extract it to any folder or USB flash drive and run RenameSense.exe directly.

Can I undo a rename batch after closing or restarting the app?

Yes. Every completed transaction is committed to a persistent Write-Ahead Log (WAL) located in your local application data directory. Even if you close the application or restart Windows, the Audit History ledger allows you to roll back previous batches with 100% fidelity.

How does RenameSense handle case-only renaming on Windows?

Windows filesystems (NTFS and ReFS) are case-preserving but case-insensitive. Changing photo.jpg to PHOTO.JPG directly can cause collisions on standard tools. RenameSense executes a two-phase staging operation through an intermediate temporary UUID, guaranteeing zero file loss.

Does the AI Regex Assistant send my filenames to the cloud?

No. The AI Assistant only sends your written prompt instruction (e.g. "extract year from brackets") to your selected AI provider (Groq or Gemini) using your own API key. Your local file names, paths, folder contents, and metadata are never uploaded or transmitted.

Does RenameSense require an internet connection or send telemetry?

No. RenameSense operates 100% offline. It contains zero background telemetry, zero analytics tracking, and zero advertising libraries. None of your file paths, filenames, or data ever leave your personal computer.

What happens if power cuts out during a batch operation?

Because RenameSense records transaction intent before disk execution, upon restarting the app, the engine identifies incomplete transactions and allows you to either finalize the remaining files or safely restore all files back to their original state.

Is RenameSense free for commercial and organizational use?

Yes. RenameSense is 100% free proprietary freeware for both personal use and organizational commercial use. You can use it across personal laptops and enterprise workstations at zero cost.

What dynamic metadata tokens are supported?

RenameSense supports {name}, {cleaned}, {ext}, {date}, {seq}, {seq:03d}, {parent}, ID3 music metadata ({artist}, {title}, {track}), and photo EXIF camera tags ({camera}, {exif_date}).

Does RenameSense require administrator rights to install?

No. The installer installs per-user into your Windows user profile (%LOCALAPPDATA%\Programs\RenameSense). It never triggers Windows UAC administrator prompts. The portable version also runs without any administrative elevation.

Can I reorder files manually before applying sequential numbers?

Yes. RenameSense features a Drag-to-Reorder sequence engine. You can drag and drop rows in the file list to set the precise sequence order before generating {seq} or {seq:03d} numbering.
